# Changelog

## 0.1.0

First release.

- Local-first Nextcloud Talk client for the Omarchy shell: SQLite mirror with full
  history and offline full-text search, sync service (`omanctalk-sync@<account>`),
  read-only helper for the interface.
- Rooms, one-to-one chats, replies, reactions, edit and delete, mentions, files and
  images, voice messages, polls (create, vote, retract, close), room management,
  favorites, archive, mute, notifications, several accounts.
- Sign-in with Nextcloud Login Flow v2 (app password).
- Based on OmaWhatsApp (MIT); see `THIRD_PARTY_NOTICES.md`.
